Design — Section 3: Files & Data Flow

What gets created, what gets modified, and how data moves through a generation query

Files to Create / Modify

🆕 CREATE: app/utils/spatial_generator.py
Pure Shapely + GeoPandas functions. No DB access. Takes GeoJSON in, returns GeoJSON out. ~400 lines. Contains: voronoi_from_points, hexagonal_grid, kernel_density_grid, suitability_score, coverage_gap_detect, etc.
✏️ MODIFY: app/utils/agent_tools.py
Add 12 new tool functions that call spatial_generator.py and handle PostGIS fetch/save. Register all in TOOL_REGISTRY.
✏️ MODIFY: app/utils/agent_orchestrator.py
Add new tools to system prompt so the agent knows they exist and when to use them.

End-to-End Data Flow: "Generate Voronoi zones for all hospitals"

1
Agent thinks → decides to call generate_voronoi on public.osm_hospitals
2
Tool in agent_tools.py queries PostGIS:
SELECT id, ST_AsGeoJSON(geom) FROM public.osm_hospitals
3
spatial_generator.voronoi_from_points(points_geojson) runs Shapely computation → returns Voronoi FeatureCollection
4
Tool saves result to temp_layers.layer_voronoi_hospitals_{hash} in PostGIS via GeoDataFrame.to_postgis()
5
Agent returns GeoJSON + layer name → frontend renders polygons on map. Agent can reference this layer in follow-up queries.

geopandas — GeoDataFrame + to_postgis

shapely ✅ already installed

Verification

1. Ask: "Generate Voronoi zones for all hospitals" → new table appears in temp_layers and renders on map

3. Ask: "Find the best location for a new clinic near transport stops" → site_suitability returns scored candidates on map
