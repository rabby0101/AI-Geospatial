Who is the primary user of this tool?

This shapes which capabilities matter most and how the interface should work

A

Urban Planners & Government Officials

City departments, municipal analysts, transport planners. They need to make evidence-based decisions about where to build infrastructure, allocate budget, or zone land.

Key need: Suitability analysis, scenario planning, trustworthy data

B

Academic Researchers & Data Scientists

University labs, think tanks, NGOs doing spatial research. They understand GIS but want a faster, conversational way to run analysis without writing SQL or Python every time.

Key need: Analytical depth, geometry generation, export capabilities

C

NGOs, Journalists & Community Advocates

Organizations fighting for equity, access, or environmental justice. They need to find and visualize spatial inequalities — who lacks healthcare, green space, or transit — without technical GIS skills.

Key need: Accessibility analysis, equity metrics, shareable maps

D

Developers & Technical Integrators

Teams building apps on top of this as a geospatial AI backend. They want an API to plug into their own products — real estate apps, logistics tools, urban dashboards.

Key need: Reliable API, rich GeoJSON output, composable tools
