End-to-End Data Flow: "Generate Voronoi zones for all hospitals"

1
Agent thinks: "I need to call generate_voronoi on public.osm_hospitals"
2
Tool in agent_tools.py queries PostGIS: SELECT id, ST_AsGeoJSON(geom) FROM public.osm_hospitals
3
spatial_generator.voronoi_from_points(points_geojson, clip_boundary) runs Shapely computation → returns Voronoi FeatureCollection
4
Tool saves result to temp_layers.layer_voronoi_hospitals_{hash} in PostGIS via gpd.GeoDataFrame.to_postgis()
5
Agent returns GeoJSON + layer name to frontend → map renders Voronoi polygons. Agent can reference this layer in next query.
