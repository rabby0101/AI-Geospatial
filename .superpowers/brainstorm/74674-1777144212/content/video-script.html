LinkedIn Video Script — Option C

"5 questions I asked AI before renting an apartment in Berlin" · ~90 seconds · Screen recording + voice-over

Hook (0:00–0:08)
Opening Title Card

"Today my wife and I visited an apartment in Berlin."

"Before signing anything, I opened my AI geospatial tool and asked it 5 questions."

[ Show map loading, apartment pin dropping ]

Question 1 — Address Search (0:08–0:20)
UI Prompt to type
"Show me what's around Schönhauser Allee 55, Prenzlauer Berg, Berlin"

→ Map zooms to the address. OSM layers activate. POIs appear as colored dots around the pin.

Voice-over: "First — just get your bearings. What's actually around this place?"

Question 2 — Transport (0:20–0:35)
UI Prompt to type
"Find public transport stops within 500 meters"

→ Agent reasons → executes PostGIS query → U-Bahn/S-Bahn/bus stops appear on map with distances.

Voice-over: "Can we commute without a car?"

Question 3 — Daily Shopping (0:35–0:50)
UI Prompt to type
"Are there supermarkets within walking distance?"

→ Isochrone (10-min walk) + supermarket intersect → results shown with walk time labels.

Voice-over: "My wife's non-negotiable — groceries on foot."

Question 4 — Green Spaces (0:50–1:05)
UI Prompt to type
"Find parks and green spaces nearby"

→ Parks layer loads, nearest parks highlighted, area in m² shown in agent trace.

Voice-over: "We both need somewhere to walk on weekends."

Question 5 — Overall Connectivity (1:05–1:20)
UI Prompt to type
"Is this a well-connected neighborhood? Give me a summary."

→ Agent synthesizes all layers → final_answer with connectivity summary text + map overview.

Voice-over: "And the verdict?"

Closing (1:20–1:30)
CTA Screen

"We said yes to the apartment. 🏠"

"This is what AI + geospatial data can do for real-life decisions."

[ App name / GitHub link / "What would YOU ask it?" ]
