Agentic System Design — ReAct Loop

Full architecture for the new AI Geospatial agent

The ReAct Loop

1. User Question
"How many playgrounds within 500m of Neukölln Rathaus?"
ReAct Loop (repeats until done)
Thought
LLM reasons about what to do next, given all prior observations
↓
Action
LLM outputs tool name + arguments as JSON
↓
Tool Execution
Python runs the tool, returns structured result
↓
Observation
Result appended to context; loop restarts
Final Answer
GeoJSON FeatureCollection → rendered on map

SSE Streaming to Frontend

Each event streamed in real-time:
event: thought → "I need to geocode the location first"
event: action → geocode_location("Neukölln Rathaus")
event: tool_result → { lat: 52.48, lon: 13.43 }
event: thought → "Now I'll create a 500m buffer"
event: action → create_buffer(coords, 500)
event: tool_result → { geojson: POLYGON(...) }
event: action → query_database(...)
event: tool_result → { features: [...14 items] }
event: final_answer → GeoJSON on map ✓
