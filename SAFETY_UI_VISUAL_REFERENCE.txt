INTERACTIVE CONTROLS
═══════════════════════════════════════════════════════════════════════════════

Left Panel Actions:
─────────────────
  [✓] Click checkbox to toggle layer visibility
  [🎨] Click color circle to change layer color
  [✕] Click X to remove layer from map
  [📌] Double-click to zoom to layer bounds

Map Actions:
───────────
  Click anywhere: Deselect current selection
  Click feature: Show popup with details
  Scroll wheel: Zoom in/out
  Click-drag: Pan around map
  Right-click: Show context menu (if enabled)

Search Bar:
──────────
  Type natural language queries:
  - "Show emergency services"
  - "Find high-crime areas"
  - "What's the safety score?"
  - "Show lighting coverage"

TROUBLESHOOTING CHECKLIST
═══════════════════════════════════════════════════════════════════════════════

If Safety Panel is Not Showing:
  ✓ Server is running (check terminal)
  ✓ Port 8000 is not blocked
  ✓ Frontend HTML includes safety-layers.js
  ✓ Browser console shows no errors (F12)
  ✓ API responds: curl http://localhost:8000/api/safety/mitte/summary

If Map Layers Not Appearing:
  ✓ Checkboxes in safety panel are checked
  ✓ Zoom level shows full Mitte (pan out if needed)
  ✓ Browser console shows no "Failed to load" errors
  ✓ API endpoints return data (check Network tab in F12)

If Colors Look Different:
  ✓ Hard refresh browser (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac)
  ✓ Clear browser cache
  ✓ Check CSS file is loaded (Network tab → safety-styles.css)

If Popups Don't Appear:
  ✓ Click directly on feature (not near it)
  ✓ Check that feature's data is loaded
  ✓ Try different feature type
